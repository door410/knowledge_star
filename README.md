# 知識網

個人知識工具：把文章、影片分析拆成知識點，長成一張看得見關聯的圖。不用安裝 Python。

## 新電腦安裝
1. 這一頁右上綠色「Code」→「Download ZIP」，解壓縮到想放的地方（例如 `C:\dev-knowledge\knowledge`）
2. 雙擊「安裝（雙擊）.bat」→ 桌面會出現「知識網」捷徑
3. 點捷徑打開 → 按「連上資料夾」選「我的雲端硬碟」（需要先裝 Google 雲端硬碟電腦版）

詳細用法見「使用說明.md」。

## 讓 Claude 查你的知識網（MCP，可選）
雙擊「安裝 MCP（雙擊）.bat」→ 重新打開 Claude 桌面版。需要 Node.js（沒有的話安裝程式會打開下載頁）。只讀，標「私人」的不給。
