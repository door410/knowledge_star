## 一、程式基本介紹

**知識網**是一個個人知識工具：把讀到的文章、AI 的回答，拆成一個個「知識點」，再用線連起來，變成一張看得見關聯的圖（像一張星空圖）。

- 有**手機版（Android）**和**電腦版（Windows）**，兩邊用 Google 雲端硬碟同步。
- 分兩個版本，資料完全相通：
  - **無 AI 版（推薦）**：完全不用 AI，自己在原文上選字變成知識點。
  - **AI 版**：多了「把文章複製給 AI 拆」、問答的 AI 回答、導覽、圈選整理。
- 同一台裝置只會有一個知識網：裝另一版會直接換過去，資料保留。

## 二、功能介紹

| 功能 | 用途 | 使用情境 |
|---|---|---|
| **丟東西進去** | 貼上文章 → 拆成知識點 → 放進知識網 | 讀完一篇好文章，想把重點留下來 |
| **先存著，之後再拆** | 文章先放著，之後再處理；可打標籤、排序、勾好幾篇一起拆 | 手機上看到文章先丟，回家用電腦拆 |
| **複製給 AI 拆**（AI 版） | 產生一段文字，貼到 Gemini 或 ChatGPT，再把回答貼回來 | 長文章懶得自己挑重點 |
| **＋ 知識點** | 自己新增一個點，主題、來源、關聯都可選或自己打 | 自己想到的心得 |
| **知識點卡片** | 點一個點會出現卡片：說明｜來源｜關聯｜我的想法；可加關聯、「找相似的」 | 複習某個點、把兩個點連起來 |
| **問答** | 打字即時找相關知識點（關鍵字＋裝在裝置裡的「意思模型」，不用網路）；有 AI 金鑰時多一段 AI 回答 | 「我之前讀過什麼跟 X 有關的？」 |
| **星空／簡約 兩種畫面** | 星空＝金色星球；簡約＝黑或白底的點和線 | 依心情切換 |
| **最近消化、每月成長** | 看最近加了什麼、每月長了多少 | 回顧自己的學習量 |
| **導覽**（AI 版） | 選一個主題，一站一站帶你看，最後告訴你還缺什麼 | 複習整個主題 |
| **時光機** | 看以前某一天的知識網，也能跟現在比 | 看自己成長 |
| **圈選整理**（AI 版） | 框住一群點，AI 建議合併、搬主題、加關聯，勾了才套用 | 點太亂時整理 |
| **主題整理** | 主題、子主題改名、搬家、合併 | 分類要調整時 |
| **紀錄與復原** | 刪掉、改掉、合併的知識點都能救回 | 不小心刪錯 |
| **同步與備份** | Google 雲端硬碟同步、每週自動備份、還原、回收桶（留 60 天） | 換手機、資料救援 |
| **外觀、編輯版面、純粹瀏覽** | 改顏色字大小；拖曳按鈕、改名、收起來；純粹瀏覽＝按鈕全藏只看網（按 Esc 或 P 回來） | 把介面排成自己順手的樣子 |
| **編輯台** | 設定知識網和卡片顯示什麼、快捷鍵、AI 拆解提示詞 | 進階調整 |
| **MCP 接頭**（電腦，選用） | 讓 Claude 桌面版能查你的知識網（只讀，私人的不給） | 想讓 Claude 參考你的知識 |

## 三、操作教學

### 1. 打開
- 手機：點「知識網」App 圖示。電腦：點桌面「知識網」。

### 2. 第一次設定同步（每台裝置做一次）
1. 按右上「設定」→「同步與備份」
2. 按「連接 Google 雲端硬碟」→ 登入**同一個** Google 帳號 → 允許
3. 之後會自動同步，不用再管。

### 3. 丟一篇文章進去（無 AI 版範例）
1. 按左上「＋ 丟東西進去」
2. 把文章貼到框裡 → 按「開始拆」
3. 在原文上用手指或滑鼠**反白一段字** → 按「把選的字變成知識點」（也可以按「＋ 自己加一個點」）
4. 重複幾次 → 按「放進知識網」
- 中途跳出去也沒關係，再按「丟東西進去」會回到剛剛那一步；左上角「←」回上一步。

### 4. 用 AI 拆（AI 版範例）
1. 「＋ 丟東西進去」→ 貼上文章 →「複製給 AI」
2. 打開 Gemini 或 ChatGPT 網頁，貼上、送出
3. 把 AI 的整段回答複製，貼回知識網 →「先看拆解」
4. 看一下知識點和關聯，名字可以點了改 → 放進知識網
- 勾「私人」的文章不送 AI，也不會給 MCP 看。

### 5. 查東西
- 按「問答」→ 打字，結果會即時出來；點下面的「相關」詞可以換詞再找。
- 在畫面上點一個點 → 看卡片 →「找相似的」找意思相近的其他點。

### 6. 救回刪掉的東西
- 「整理 → 紀錄與復原」，或「設定 → 同步與備份 → 回收桶」。

## 四、安裝與啟動（換電腦、換手機）

**下載頁：** https://github.com/door410/knowledge_star/releases/latest

| | 無 AI 版 | AI 版 |
|---|---|---|
| 手機 | knowledge-star-noai.apk | knowledge-star.apk |
| 電腦 | knowledge-star-noai-setup.exe | knowledge-star-setup.exe |

**手機：**
1. 用手機瀏覽器打開下載頁 → 點 .apk 下載 → 打開
2. 第一次會問「允許安裝不明來源的應用程式」→ 按允許 → 安裝
3. 打開 App →「設定 → 同步與備份 → 連接 Google 雲端硬碟」→ 登入同一個帳號，資料就會從雲端回來

**電腦：**
1. 下載 .exe → 雙擊 → 一直按下一步 → 桌面出現「知識網」
2. 一樣到「同步與備份」連接 Google 雲端硬碟
3. 如果有舊的「知識網資料」資料夾：「設定 → 同步與備份 → 匯入舊的知識網資料夾」

**更新程式：** 下載新版安裝檔直接裝上去，資料會保留。

**給別人用：** 把下載頁網址給對方，他用**自己的** Google 帳號連接，資料各自獨立，不會看到你的。

## 五、程式怎麼運作（白話版）

把它想成一本**活頁筆記本**：

1. **你寫進去**：每個知識點是一張活頁紙（電腦上就是一個 Markdown 文字檔，Markdown＝有簡單格式記號的純文字）。
2. **App 把紙畫成圖**：程式讀所有活頁紙，每張畫成一個點，紙上寫的「關聯」畫成線。
3. **影印一份放雲端**：每台裝置把自己的整本筆記放一份到 Google 雲端硬碟，並讀其他裝置的那份來合併。
   - 兩台同時改同一個點 → 兩個版本都留（在「同步與備份」可以改用另一版）
   - 一台刪、另一台改 → 留改過的
4. **每週拍一張照存檔**：自動把整本筆記打包成 .zip 備份，留最近 8 份。

**程式的組成：** 核心是一個網頁（「知識網.html」＋一堆 .js 檔）。電腦版用 Electron 包裝（像一個專門放這個網頁的視窗），手機版用 Capacitor 包裝（同樣的網頁變成 App）。**所以改一次網頁，手機和電腦都會跟著變。**

**安裝檔怎麼來的：** 把程式推到 GitHub 的 `main` 分支 → GitHub 自動測試、做出四個安裝檔、放上下載頁（這叫 GitHub Actions，像一台雲端自動工廠）。

## 六、重要檔案與資料位置

### 你的資料（最重要）
| 位置 | 說明 |
|---|---|
| 電腦：`文件\知識網資料` | 所有知識點（Markdown，Obsidian 也打得開） |
| 手機：App 自己的空間 | **解除安裝會刪掉**，但雲端和備份都還有 |
| Google 雲端硬碟「知識網同步（請勿手動修改）」 | 每台裝置一個檔，每個都是完整的一份。**不要手動改或刪** |
| 備份：電腦 `文件\知識網備份`；手機 `Documents／知識網備份` | 每週一份、留 8 份；.zip 解開就是 Markdown 資料夾 |

資料夾裡的分區：`00-收件匣`（先存著的文章）、`02-知識`（知識點，每篇來源一個資料夾）、`03-我的`、`04-知識網`（設定，含各裝置的介面設定）。

### 程式檔（在 `C:\dev-knowledge\knowledge_star`）
| 檔案 | 是什麼 |
|---|---|
| `知識網.html` | 主畫面 |
| `menu.js`、`layout.js` | 選單、按鈕排列、外觀 |
| `folder.js`、`vfs.js` | 讀寫資料 |
| `sync-core.js`、`sync.js` | 同步規則、備份、回收桶 |
| `ai.js` | AI 設定（用哪家、哪個模型） |
| `mcp/` | 給 Claude 桌面版的接頭 |
| `android/`、`electron/`、`native/` | 手機、電腦的包裝 |
| `.github/workflows/build.yml`、`scripts/ci/` | 自動做安裝檔的流程 |

### 不能亂刪、亂改
- **App 簽章檔**：正本在 Google 雲端硬碟「知識工具／App簽章（不可刪）」。**弄丟了，手機以後就無法直接更新，只能解除安裝重裝。**
- GitHub 上的 Secrets（密碼類設定，見第七節）
- 雲端硬碟「知識網同步」資料夾、`android/`、`electron/`、`.github/`、`package.json`
- 可以放心刪（會自動重建）：`node_modules/`、`www/`

## 七、未來維護與修改

### 改程式的固定流程
1. 用 VS Code 打開 `C:\dev-knowledge\knowledge_star`
2. 先在本機「練習場」試（不會動到真資料）：終端機執行 `python -m http.server 8765`，瀏覽器開 `http://localhost:8765/知識網.html?vfs=1`（無 AI 版加 `&plain=1`）
3. 改好、確認沒問題 → 推到 GitHub 的 `main` → 約十幾分鐘後下載頁出現新版本 → 手機電腦各自下載安裝
- 詳細步驟、可重複用的 AI 提示詞，看「我的程式自主維護說明書.md」第 5、6 節。
- 可以請 Claude 或其他 AI 幫忙，開場說「先讀 README.md 和 docs/PROJECT_FINAL_REPORT.md」。

### 換 AI 模型或金鑰
- **使用者這端**：AI 版裡打開「AI 設定」貼上 Gemini 或 Groq 的金鑰。金鑰只存在你的裝置。
- **程式這端**：預設模型寫在 `ai.js` 最上面（目前 Gemini 是 `gemini-3.8-flash`，Groq 是 `llama-3.3-70b-versatile`）。Google 停用舊模型時，改這裡的名字即可。
- 免費額度、模型名稱會變，以 Google／Groq 官方頁為準。

### GitHub Secrets（只記名字，不記內容）
在 GitHub 專案 → Settings → Secrets 裡：`ANDROID_KEYSTORE_BASE64`、`ANDROID_KEYSTORE_PASSWORD`（手機簽章）、`GOOGLE_DESKTOP_ID`、`GOOGLE_DESKTOP_SECRET`（電腦版登入 Google 用）。少了任何一個，自動建置會失敗。

### 要特別小心
- 改 `sync-core.js`（同步規則）之前一定先跑測試 `npm test`，改錯可能讓兩台裝置資料互相蓋掉。
- 不要把金鑰、密碼、簽章檔貼給 AI 或放進程式碼。
- 大改之前先 commit（存檔點），改壞了才能回去。

## 八、常見問題

| 狀況 | 原因 | 怎麼做 |
|---|---|---|
| 手機裝不起來 | 沒允許「不明來源」 | 照提示到設定允許，再點一次 .apk |
| 手機更新時說「與現有套件衝突」 | 簽章不同（可能簽章檔換過） | 先確認雲端有同步、有備份 → 解除安裝 → 裝新版 → 重新連接雲端 |
| 兩台資料不一樣 | 還沒同步完、或連的是不同 Google 帳號 | 兩台都到「同步與備份」看帳號是否同一個，按同步 |
| 同一個點出現兩個版本 | 兩台同時改了 | 到「同步與備份」選要用哪一版 |
| 刪錯東西 | — | 「紀錄與復原」或「回收桶」（60 天內） |
| 整個資料壞了 | — | 「同步與備份 → 還原」，選一份每週備份 |
| AI 拆解或 AI 回答失敗 | 金鑰錯、額度用完、模型被停用 | 換金鑰；或先改用「複製給 AI」手動貼網頁版；模型停用就改 `ai.js` |
| 下載頁沒有新版本 | 自動建置失敗 | GitHub 專案 →「Actions」看紅叉的那次，把錯誤訊息丟給 AI 問 |
| 按鈕排亂了找不到功能 | 編輯版面拖亂 | 選單裡的「全部功能」可以列出所有功能（含收起來的） |
| MCP 查不到資料 | MCP 還在讀舊位置（見第九節） | 重新雙擊「安裝 MCP（雙擊）.bat」，手動選 `文件\知識網資料` |
